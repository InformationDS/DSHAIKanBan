# 公共规则：对象、归属与状态

来源：v1.17 第 2.3、4、5、6、14.4、17.2 章与 FR-01、07—12、24—26、32。本文是有效公共需求；对应功能首次实现时即须遵守。

## OBJ-01 项目边界与空状态

任务、项目对话、四类正式内容、草稿、待确认、归档与界面偏好均归属明确项目。切换项目一起切换，不按同名对象合并、不跨项目共享。项目名称可见，同名项目显示位置等辨识。新项目全部为空，无正式演示任务、对话、记录或草稿；示例与试用数据只用于验收。

工作范围不可用不删除管理数据；更改项目位置不自动改已有对话范围，不移动用户文件。缺失范围不能由系统猜测另一项目。

## OBJ-02 任务状态由用户决定

任务状态为未开始、进行中、已阻塞、已完成、已取消。默认未开始；阻塞原因必填。已完成/已取消可重新打开。归档是可见性属性，不是第六种状态。已取消默认收起，已完成不自动归档。

用户拖动、菜单或明确管理指令决定状态。创建/打开对话、AI 响应结束、记录确认、项目成果保存都不自动改状态。完成不强制全部工作停止或形成记录，不自动生成项目记录。阻塞、取消、归档均不自动停止 AI。

## OBJ-03 工作对话归属

项目对话首次关联任务前可为空；未关联可以正常工作，只使用项目背景。任务拥有多条对话，工作对话首次关联后固定属于一个同项目任务，不解除、改绑或跨任务转移。任务删除也不释放归属。

关联不复制/改写原始消息、不确认旧成果、不自动整理或执行、不更改任务状态；运行中关联不打断本轮，任务背景在下次用户明确发送时提供。关联前展示目标和不可改绑含删除后果的就地提示，不加确认弹窗；任务内新建就地提示固定归属。

## OBJ-04 系统整理对话

项目成果生成/总览建议由系统创建整理对话执行，标明项目、本次整理、来源任务。它不计入任务工作对话、工作数量或未形成记录提示，不允许绑定为工作对话，不生成自身任务记录。查看过程不执行工作。

一次新整理使用新上下文；同次失败重试、已有草稿打开及审核更新建议沿用本次执行载体并先核对结果。工作成果来源与整理过程来源分别标记。

## OBJ-05 四类正式内容的职责

| 对象 | 唯一性与作用 |
| --- | --- |
| 任务记录 | 每条工作对话在唯一任务中一份当前记录，阶段成果细节，可更新 |
| 任务概况 | 每任务一份当前概况，多个记录当前有效贡献与人工修正的精简汇总 |
| 项目记录 | 每成果任务一份当前条目，完成边界、成果细节和来源截止 |
| 项目总览 | 每项目一份当前总览，目标、共同约定、有效成果索引、依赖、风险 |

概况不能由最后确认的记录整体覆盖，总览不能逐条堆叠成果全文。任务标题、目标、状态、原因由任务字段提供，不在概况维护另一套状态；项目共同约定属于总览，不另建重复事实源。无对话可手动编辑概况，无成果可初始化总览，不伪造来源记录。

## OBJ-06 对话运行与记录更新状态

运行表达可输入、正在处理、等待回答、等待具体执行确认、本轮结束、正在停止、已停止、失败、需要核对；依据实际运行结果，不以页面打开当运行、响应结束当任务完成。

记录更新表达整理中、待确认、需要核对、已确认、已放弃、整理失败/已取消。业务未决结论用“待确认结论”；汇总一致性用“概况待核对/总览待核对”，不得泛化成相同标签。前者允许作为未决问题保存，后者阻止正式成对保存。

## OBJ-07 草稿粒度与计数

每对话任务记录最多一份活动草稿；每任务项目记录最多一份活动草稿。手动概况/总览草稿独立保存，不覆盖记录草稿。不同记录可同时整理，不设置任务级/项目级全局草稿锁。

一条记录及其汇总候选算一个确认项。已确认、已放弃、整理中不计可确认数量；需核对明确标识。成果未生成/待更新属于行动提示，不凭空产生草稿或增加确认数量。

## OBJ-08 展示来源与提示

卡片进展来自正式概况，无概况用目标；草稿、最后一条记录均不能冒充任务整体状态。对话列表用桌面真实标题及状态，同名用时间等区分，历史参与折叠。无法打开来源保留标识及已确认贡献，不清空成果。

新内容提醒只判断上次成功整理处理位置后有无新增实际交流，在本轮结束时提示；整理要求/回复不算新工作。无记录显示尚未形成记录。成功保存或成功判定两部分无需更新推进处理位置；失败、取消、放弃、仅出草稿、保存失败不推进。提醒不阻止另开对话或完成任务。

## OBJ-09 删除后的固定来源

仅归档任务可永久删除，必须明确影响并二次确认；运行中先结束工作。管理任务删除不删除聊天/代码，不删除已确认项目成果，成果保留来源已删除及必要标识，不指向同名新任务。

原对话保留任务名称/来源，仍可聊天，只准备项目背景；禁用形成任务记录、返回任务改为返回项目、不再新增任务整理草稿或新内容提示；不成为未关联候选，仍在全部/已关联中可见。重启后保持。归档期间新工作、整理及确认前先恢复，已有整理可完成为草稿而不自动确认。

## OBJ-10 管理动作与执行权限

新建、关联、打开、预览、复制、背景变更不启动 Agent。用户发送本轮要求才执行工作；点击整理授权本次整理而不授权继续开发。整理只读必要材料并生成候选，不改代码、执行验证、自动确认或改任务状态。

普通可撤销管理变化不反复确认；永久删除、AI 正式内容确认与具体执行权限审批分别表达，不能跨性质全部确认。对话阶段结束、任务完成、生成项目成果三种意图必须分开。

## 术语：项目记录、项目总览、项目成果、汇总

本节只统一用词，不改变上述任何规则的行为；各功能 PRD 与公共规则引用这些对象时按本节口径。

- **项目记录**：每成果任务一份的当前成果条目，记录完成边界、成果细节和来源截止（唯一性与作用见 OBJ-05）。
- **项目总览**：项目级精简汇总，每项目一份（见 OBJ-05）。
- **项目成果**：项目记录与项目总览的合称；「生成项目成果」指生成项目记录与总览候选，两者仍按成对确认生效，不另指第三类对象。
- **汇总**：概况与总览的合称；单说「概况」指任务概况，单说「总览」指项目总览。需要精确表达时写全「任务概况」「项目总览」，不笼统用「成果」代替。
