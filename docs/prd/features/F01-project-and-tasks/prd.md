## 1. 目标与范围

用户无需开启 AI 或对话，即可在当前项目创建、编辑任务。
切换项目后，看板与管理信息明确归属，不出现其他项目的内容。
仅有标题的任务能可靠保存，目标说明可以稍后补充。

包含项目入口、项目范围辨识、空看板、单条任务创建、标题及目标编辑和重要活动记录。
项目选择复用宿主能力；本功能不另外建设账号、模型或工作区管理系统。
状态流转与卡片详情呈现由 F02 实现，概况维护由 F03 实现。
批量创建属于 P1；AI 自动拆解项目目标属于 P2，不在本功能首版范围。

实现必须使用稳定项目标识区分同名项目，不用名称作为数据归属键。

F17 加入归档后，项目切换还须切换归档列表，不能落回全局列表。

## 3. 用户流程与界面职责

1. 选择项目并打开看板，项目名称始终可见。
2. 首次空项目显示空看板和“新建任务”，不要求用户先创建对话。
3. 点击新建，输入标题，可选填目标说明。
4. 标题无效时就地说明，保留用户输入；有效时提交保存。
5. 保存中反馈处理中，保存成功后出现唯一任务，可直接打开详情。
6. 详情中修改标题或目标，确认保存后同步当前字段与更新时间。
7. 返回看板，保留当前项目位置；切换项目后恢复另一项目自身位置。

同名项目显示位置等辨识信息，同名任务允许独立存在。
无项目或项目信息读取失败的状态应明确，不能把失败伪装成新空项目。
工作范围不可用与管理数据不可用分别提示。

## 4. 功能规则

### F01-R01：项目拥有独立管理数据

任务、概况、记录、总览、待确认、归档及看板偏好全部按项目分别读取与保存。
切换项目时一并切换；加载过程中不得暂时把旧项目内容标成新项目。
无对话、关闭全部对话、AI 不可用均不影响本地看板入口。

### F01-R02：任务创建输入

标题必填，只有空白字符视为无效；目标说明选填。
未填写说明时标题是最简目标，不生成额外需求文本。
默认状态为未开始；通过列内创建选择其他状态时交给 F02 校验。
在阻塞列创建必须填写原因；取消原因输入不创建半成品正式任务。

### F01-R03：无副作用创建

创建任务不调用 AI、不创建工作对话、不生成任务记录、概况或项目成果版本。
任务自动归属操作发起时核对的当前项目。
操作中切换项目时，结果仍归属已明确的原项目，不写入刚切换的项目。
成功结果必须报告任务及归属项目，不依据页面当前名称猜测。

### F01-R04：重复与重试

同一次提交连点、超时重试、恢复结果核对只产生一个任务。
创建成功后的再次主动新建是独立操作，允许使用相同标题。
不以“同名任务存在”作为自动合并依据。
结果未知先核对是否已保存，再补失败步骤。

### F01-R05：当前用户字段

标题、目标由用户直接编辑；当前字段独立于记录和概况。
保存失败维持此前正式字段，输入保留为草稿。
打开页面和每次键入不算实质更新；成功的实质修改才更新时间。
目标实质变化时标记需要核对相关概况与结论适用范围。
普通重命名不整体废弃已有成果或所有记录草稿。

### F01-R06：字段与来源分离

记录审核期间修改目标或状态，后续记录确认不能覆盖这些新字段。
展示当前目标及需核对提示，由 F07/F08/F09 接续处理相关影响。
用户字段建议与当前值分开，主动选择后才保存，AI 提议本身不生效。

### F01-R07：工作范围与活动历史

工作范围缺失时保留管理数据，依赖文件的工作提示补充范围。
不猜测或借用其他项目文件；更改项目位置不移动或删除代码。
已有对话工作范围不随项目位置修改而自动变化。
重要活动记录至少能查目标、状态、归属和确认变化，不存每次键入流水。

## 5. 异常、取消与恢复

| 场景 | 用户可见结果与恢复 |
| --- | --- |
| 标题空白 | 就地校验，不创建对象，不清目标说明 |
| 创建失败 | 正式列表保持不变，保留标题/说明，允许重试同次提交 |
| 保存结果未知 | 显示需核对，查询同次操作结果，不盲目创建第二项 |
| 编辑后离开 | 保留草稿或提示处理；不得静默丢弃输入 |
| 取消创建 | 不产生正式任务；已经保存成功的任务不能被称为未创建 |
| 另一处已修改字段 | 展示当前值和本地编辑，核对差异，不用旧草稿覆盖 |
| 项目读取失败 | 保留已知数据，重试读取，不清空存储、不自动新建项目 |
| AI 不可用 | 创建、编辑、查看仍可用；本功能无 AI 重试 |
| 重启 | 恢复已保存任务和可用草稿，未知保存先核对，不重发创建 |
