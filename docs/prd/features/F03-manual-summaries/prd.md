## 1. 目标与范围

用户无需 AI、对话或已完成任务，即可维护可信的当前任务背景与项目背景。
手动修改先预览、后保存，正式内容有用户来源和版本，失败不丢编辑。
任务概况表达整体进展、有效决策、问题和下一步。
项目总览表达项目目标与范围、共享约定、有效决策、成果索引、依赖、风险和后续方向。

包含两类汇总的初始化、直接编辑、差异预览、正式版本保存与简要版本信息。
四类内容的完整历史查看/恢复归 F10，但 S1 即须保存不可覆盖的版本。
任务记录生成归 F06，项目成果生成归 F13；本功能不虚构这些来源。
明确修正已有关键结论的完整作用范围归 F09，存在来源后必须联合接入。

## 3. 用户流程与界面职责

1. 无概况的任务显示“暂无任务概况”，提供编辑入口。
2. 用户直接填写进展、决策、问题和下一步，可只维护本次需要的内容。
3. 点击预览查看当前正式值与候选差异、用户修改来源。
4. 确认后形成当前概况版本，卡片同步正式进展。
5. 在项目总览同样可初始化目标、约定和约束，不要求先完成任务。
6. 离开编辑页保留草稿或提示处理，返回能继续。
7. 已有来源结论时，明确修正动作进入 F09 同次预览，不要求先改来源正文。

不要为“进展”“下一步”另外维护一份表单数据。
显示当前版本和时间，历史正文不默认展开或投递给 AI。
总览共享约定是总览的一部分，不另建重复事实源。

## 4. 功能规则

### F03-R01：独立初始化

任务无对话时允许保存概况，不产生任务记录、不伪造来源对话。
项目无完成任务时允许保存目标与约束，不产生项目成果记录。
空内容显示暂无，不能预置假进度、验证或成果。
当前正式概况不可核对时明确提示，允许查看来源，不拿候选代替正式内容。

### F03-R02：人工编辑和正式保存

直接编辑记录为用户修改；确认预览后生效，不原地覆盖历史。
保存实质变化产生新版本，记录确认时间、前一版本、用户来源和修改结果。
人工修正可填写依据但不强制理由；无变化不制造新版本。
保存成功后才改变卡片、总览和后续背景读取内容。
保存中或失败不显示“已同步”，输入仍为可恢复草稿。

### F03-R03：来源与控制边界

直接修正概况/总览不回写原始聊天，不改造任务记录或项目记录正文。
不改任务标题、目标、阻塞原因或状态，不改对话运行状态。
人工修改的来源标注不能冒充 AI 原稿，也不能把不存在对话设为来源。
若任务目标已改变，当前目标独立可见，提示核对概况适用范围。

### F03-R04：后续更新保留人工修正

AI 提出变化时保留仍有效人工修正与其他来源贡献。
相反结论或替代建议须显示相关差异，由用户决定；不能静默覆盖。
草稿审核期间另一处修改汇总，旧草稿需核对当前基线，保留人工输入。
普通重命名不把概况全部废弃；目标实质变化仅核对相关范围。

### F03-R05：结论修正和摘要删减

删减摘要中的一句只代表汇总编辑，不自动否定来源记录结论。
明确否定、替代或调整范围须关联受影响片段、适用范围与修正说明。
相关概况修正和片段适用性在同次预览确认一致生效；失败均维持此前结果。
不能按同名文字跨任务扩散修正，也不能仅凭后保存时间裁定冲突。
后续 AI、历史恢复或重启不能自动恢复被否定结论的效力。
S1 若没有来源，不制造片段；来源加入后必须接 F09，禁止简化为纯文本覆盖。

### F03-R06：总览与概况内容边界

概况汇总整项任务的有效成果与人工修正，不以末条记录全文替换。
总览保持精简，不逐条粘贴所有成果、聊天或历史版本。
保留关键风险与约束；细节放相应正式记录并按需读取。
总览成果描述有截止范围，不成为自动改变看板状态的依据。
不跨项目共享，不替代正式需求或仓库事实文档，不自动改写代码或文件。

### F03-R07：独立草稿和重复操作

手动概况/总览草稿独立于记录成对草稿，不能互相覆盖。
同一确认连点、超时重试或两窗口提交只产生一个有效版本。
结果未知先核对；仅补失败保存，不重建对象或调用 AI。
放弃手动草稿保留正式内容和其他来源草稿。

## 5. 异常、取消与恢复

| 场景 | 用户可见结果与恢复 |
| --- | --- |
| 保存失败 | 正式旧版本保持，保留输入、差异和选择，可重试 |
| 取消预览 | 返回编辑或保留草稿；明确放弃才清本次草稿，正式内容不删 |
| 离开/重启 | 恢复已保存正式内容和可用草稿，不能把草稿自动确认 |
| 来源变化/竞争编辑 | 显示最新基线与差异，核对相关范围，不覆盖用户输入 |
| AI 不可用 | 全部本功能操作本地可用；不要求更新建议成功才允许手动保存 |
| 源对话不可打开 | 保留来源标识及已确认贡献，可手动维护，不宣称完成源对话整理 |
| 读取失败 | 保留已有内容，提示重试，不能清空后覆盖为“暂无” |
| 保存结果未知 | 显示需核对，不重复版本，不自动重发 AI 工作 |

## 7. 实施边界与交接

可调整编辑表单及差异呈现，不能增加强制 AI 步骤或重复进展事实源。
改动范围为两类汇总、版本、手动草稿、预览和本地保存。
S1 必须交付版本与草稿保留；完整历史恢复留 F10，不提前改变其语义。

验收时创建 verification.md，记录离线、失败、重启及无虚构来源证据。
