## 1. 目标与范围

用户能在项目内直接开展对话，也能为指定任务开启独立对话并继续任意既有对话。
打开和创建只准备工作入口，实际工作等待用户发送本次要求。
包含项目与任务新建入口、唯一创建、自动任务归属、跳转、列表、继续和来源展示。
已有对话绑定由 F05 实现，整理记录由 F06 实现。
默认背景、准备与发送同步由 F11 实现；F04 与 F11 必须联合完成 S2 可用闭环。
系统项目整理对话由 F13 创建，不能混入本功能工作对话列表或归属候选。

## 3. 用户流程与界面职责

1. 项目对话列表点击新建，无需选任务，创建项目内未关联工作对话。
2. 任务详情固定显示新建对话，就地提示固定归属当前任务。
3. 任务新建依次报告创建、归属、背景准备及跳转的实际结果。
4. 用户在对话内输入本次要求，发送后才开始工作。
5. 列表点击具体行直接打开，不先跳额外管理页面。
6. 快捷继续打开最近实际使用对话，用户可改选其他目标。
7. 回到任务可继续另一条对话或新建，不需上一条先整理或结束。

项目列表展示真实标题、运行状态和归属，可搜索标题、按全部/未关联/已关联筛选。
任务详情默认当前参与对话，历史参与折叠；记录正文和历史按需展开。
未关联侧栏显示项目与“未关联任务”，不展示虚构任务状态或概况。

## 4. 功能规则

### F04-R01：项目内新建

项目入口新建的任务归属为空，这是正常结果，不是归属失败。
不使用最近任务或曾打开的卡片隐式绑定，不强迫创建任务。
未关联对话正常支持发送、运行、暂停、停止和继续。
没有总览仍可输入本次要求，不创建虚构任务记录或项目成果。

### F04-R02：任务内新建

新建独立对话并归属指定任务，使用任务项目范围，任务标题可作初始命名参考。
就地提示“此对话固定属于当前任务”，不增加确认弹窗。
不复制另一对话完整历史，不要求用户再次手动绑定。
有其他对话运行、尚无记录或存在草稿不阻止新建。
归档任务须先恢复，已删除任务不能创建任务工作对话。

### F04-R03：创建流程与补偿

同次快速点击仅创建一条，完成后再次主动发起才是一条新对话。
创建、归属、准备和打开分别显示结果；重试只补失败步骤。
创建成功后保存该对话标识，归属失败不另建对话，保留用户输入。
结果未知先核对，不能把失败标成完整成功。
归属未成功前不能按任务对话生成记录或宣称任务背景已使用。

### F04-R04：打开与背景职责

打开不自动发送继续指令、不改任务状态、不形成记录、不自行工作。
正在运行的对话打开后展示实际工作，而非再次执行。
当前概况/总览变化时显示“背景有更新，下次发送时自动同步”。
具体比较、范围、快照和使用登记由 F11 处理，不增加手动刷新确认步骤。
准备未完成时发送须等待或明确选择暂不带背景，不能静默漏掉。
准备和关联不等于已使用背景；实际提供后才由 F11 登记。

### F04-R05：列表和命名

标题与桌面对话同步，不另设看板昵称；同名用时间和简短信息区分。
显示实际工作状态、最近阶段、任务记录存在情况与最近成功整理处理位置。
未关联没有任务记录时不能显示该任务待整理；任务归属存在但从未记录显示尚未形成。
系统整理对话不参与任务工作数量、绑定候选和未记录工作提示。

### F04-R06：记录与新内容提示

形成记录不关闭对话，继续工作后更新同一份记录，版本由 F06 保留。
有记录对话在成功处理位置后出现新增实际交流，本轮结束时提示有新内容待整理。
仅判断新增交流，不把其价值或成功与否当作提示条件。
整理指令、整理回复和未确认候选不成为新工作，不自我触发提示。
无实质变化的成功整理可推进位置；更新草稿仅保存成功后推进，失败/取消/放弃不推进。
提示不阻止新建对话、继续或完成任务。

### F04-R07：来源不可用

来源对话打不开时保留对话标识、正式记录、历史与概况贡献。
提供在任务内新建对话，不清空已有成果或假称已继续。
侧栏展示归属、当前概况和实际背景范围；删除来源由 F17 替换相应入口。

## 5. 异常、取消与恢复

| 场景 | 用户可见结果与恢复 |
| --- | --- |
| 创建失败 | 输入保留，可重试同次创建，不生成幽灵行 |
| 创建成功归属失败 | 保存对话标识，只重试同一归属，不复制消息、不再创建 |
| 背景准备失败 | 对话仍存在，输入保留，F11 提供重试或明确无背景路径 |
| 打开失败 | 保留来源与记录，允许新开目标任务对话 |
| 取消未发送 | 无执行；已经成功的创建不假称未发生 |
| 来源/背景更新 | 展示更新提示，正在运行快照不被中途替换 |
| AI 不可用 | 空对话可创建则保留入口；发送明确不可用，不能声称已工作 |
| 重启/中断未知 | 恢复归属与列表，核对已创建步骤，不自动重发工作 |
