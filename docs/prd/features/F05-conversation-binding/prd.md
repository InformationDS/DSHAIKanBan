## 1. 目标与范围

用户先在项目中开展对话，之后能将其固定关联至一个任务，保留原有工作。
关联不改写聊天，不确认成果，不启动工作；绑定一旦成功就不能解除或改绑。
包含双向关联入口、同项目候选搜索、目标提示、唯一关系保存和整理前选任务桥接。
记录生成及成对确认由 F06 负责，发送时任务背景接入 F11。
不包含跨任务转移、解除绑定、复制对话或跨项目关联。

F04 新建任务对话与本功能使用同一固定关系，不能提供不同解绑能力。
F01 提供目标创建；创建成功但关联失败应复用同一目标任务。
F06 从未关联对话形成记录时调用本流程，成功后接续同一整理意图。
F11 在用户下一次发送时补充任务背景，不因为关联自动执行。
F17 删除任务保留来源墓碑；该对话永远不会重新成为未关联候选。
归档任务须由 F17 恢复后才能作为关联目标。

## 3. 用户流程与界面职责

1. 任务详情点击“关联已有对话”，打开当前项目工作对话候选。
2. 默认优先展示未关联对话，支持标题搜索及查看真实运行状态。
3. 选择未关联对话，显示目标任务名称与固定归属说明。
4. 点击关联即保存，不增加第二个确认弹窗。
5. 未关联对话侧栏也可“关联任务”，选择当前项目有效目标。
6. 关联成功后显示归属和下一次发送的背景提示，不发送隐藏消息。
7. 从未关联对话点“形成任务记录”时，先选/创建任务，成功关联后交 F06。

其他任务对话可供查看已有归属，但不能选为关联候选。
已属于当前任务显示已关联，不重复添加；来源不可打开明确标注，不做无提示候选。
就地提示文案必须包含删除后果，无需新增额外弹窗。

## 4. 功能规则

### F05-R01：候选范围

仅当前项目可用且从未绑定任务的工作对话可以新关联。
系统整理对话、其他项目对话、已有绑定及删除来源对话不可选。
目标是当前项目有效且未归档任务；归档先恢复，已删除不能选择。
查询失败不当成“没有可关联对话”，展示重试。

### F05-R02：唯一固定关系

一项任务可关联多条对话，一条对话最多服务一项任务。
首次关联前任务可为空；成功后固定，不提供解除、改绑或跨任务转移。
同任务重复关联返回已有成功关系，不重复创建。
并行选择两个任务时只能一个关系生效，另一处展示实际归属，禁止覆盖。
任务归档、删除、重启或同名新任务均不释放固定来源。

### F05-R03：明确目标和就地说明

关联前明确显示目标名称，在关联按钮旁提示：
“关联后不可解除或改绑。即使任务被删除，此对话也不能关联其他任务。”
点击关联即完成授权保存，不增加额外确认弹窗。
任务内新建由 F04 提示固定归属，不能无提示隐式绑定。
想推进另一个任务时提供新建独立对话建议，不提供复制转移快捷路径。

### F05-R04：关联不等于成果或执行

不复制、改写、清空原消息，不改任务状态、不生成正式记录或概况版本。
不自动开始工作、不发送整理指令、不确认此前聊天中的结论。
运行中未关联对话允许建立关系，不停止或打断当前执行。
关联不能登记此前已经使用任务背景，也不在本轮结束时自动发起任务工作。
任务信息按 F11 在下一次用户发送时自动提供。

### F05-R05：形成记录前选择/创建任务

未关联对话选择已有或创建目标，再完成固定关联，成功后继续同一整理意图。
选择取消且尚未关联时仍为空，不建立记录、草稿或虚构任务成果。
目标创建成功但关联失败时保留目标，重试关联同一任务，不重复创建。
关联已成功后取消整理只取消整理，明确关系保持，不自动解除。
绑定成功不是记录确认，F06 仍须提炼、同屏预览和用户确认。

### F05-R06：首次记录内容桥接

交给 F06 的来源是整条对话截至整理前的已结束实际工作。
关联前与任务相关的有效结论可以提炼，无关闲聊不搬进记录。
不要求用户选择关联前后消息范围，不增加待补录或排除标记。
相关结论仍是待审核草稿，不把关联前的发言当作已确认事实。

### F05-R07：失效来源与持久归属

固定关系保存稳定项目、任务和对话标识，不用标题匹配。
源任务删除后保留名称/标识及已关联状态，不能绑定同名新任务。
对话在全部和已关联筛选可见，未关联筛选不包含删除来源。
删除后记录禁用、返回项目、取消待用任务背景等降级由 F17/F11 接入。

## 5. 异常、取消与恢复

| 场景 | 用户可见结果与恢复 |
| --- | --- |
| 选择取消且未绑定 | 保持未关联，不创建记录或草稿 |
| 关联保存失败 | 未确认成功前不显示归属成功，选择与输入保留，可重试 |
| 保存结果未知 | 先查询实际关系，成功关系不重复创建，不盲目换目标 |
| 候选刚被另一处关联 | 展示最新目标，取消当前关联，不覆盖固定关系 |
| 目标归档/删除或项目不符 | 阻止关联，解释原因；已创建目标不重复创建 |
| 关联后取消整理 | 保留关联，F06 保留/取消其草稿，不解除关系 |
| AI 不可用 | 搜索和绑定仍可本地完成，形成记录提示 AI 不可用或转手动概况 |
| 重启 | 从未关联仍为空，已绑定保持唯一固定来源，不自动发送工作 |
