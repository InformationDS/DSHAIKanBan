## 1. 目标与范围

用户在一条工作对话相关工作结束后，点击“形成任务记录”，审核记录与任务概况，执行一次确认使可信成果生效。
本功能包含正常整理、来源范围、精简质量、活动草稿、成对预览、一次正式保存及基本失败恢复。
未编辑的正常路径在本功能内形成完整闭环，不能等待 F07 或 F08 才提供可靠保存。
F07 扩展编辑后的核对交互，F08 扩展其他窗口和其他对话引起的竞争核对；其公共保存边界从本功能首次实现就有效。
F06 单独演示/验收覆盖未编辑的正常路径。F07 尚未就绪时，实质编辑仍须保留两边草稿并阻止正式保存；F07 完成后才可验收完整编辑核对路径，不能把这种内部增量宣称为完整 S3。
不包含项目成果生成、代码修改、验证执行、任务自动完成或运行中整理调度。

## 3. 用户流程与界面职责

1. 用户在对话任务侧栏或任务详情的某条对话行点击“形成任务记录”。
2. 未关联时先选择或创建本项目任务，并完成固定归属；已关联时显示实际任务和对话。
3. 系统在这条工作对话发送可见整理要求，用户无需再输入或点击发送。
4. 进度入口显示实际阶段、对话名称和截止范围；可打开原对话查看过程。
5. 返回候选后，同屏显示“本条任务记录变化”与“任务概况变化”，默认突出增删改，允许展开全文与来源。
6. 正常未编辑路径查看后点击一次“确认保存”；正在保存时不能显示已成功。
7. 保存成功后更新正式记录、概况、卡片和后续读取；用户可返回原对话继续工作。
8. 若两部分确实均无需更新，显示“已整理，无需更新”，不创建待确认项，也不再要求确认。

没有来源对话时提供手动维护概况入口，不显示假来源记录。缺少正式概况时可生成首份概况候选。

## 4. 功能规则

### F06-R01：来源与授权

侧栏作用于当前归属任务与当前对话；详情作用于点击的对话行。不得使用页面中另一条活跃会话替代来源。
派发前再次核对项目和固定归属。点击只授权读取必要材料、整理及生成待审核候选，不授权开发、测试或正式确认。
可见要求明确“仅整理已结束工作并提出任务概况更新，不继续执行工作”。

### F06-R02：整理范围

首次和再次整理均从整条对话截至发送整理要求前的已结束实际工作提炼相关结论；关联前的相关工作也可进入。
没有消息区间选择、补录或排除操作。处理位置用于提示管理，不用作遗漏旧工作或跳过放弃内容的唯一依据。
整理指令、整理回复、生成草稿与未确认候选不作为新增成果；不能循环总结整理本身。
正常使用假设为相关工作结束后整理且整理期间无新增工作，不宣称系统已经强制保证。

### F06-R03：记录结构与精简质量

按“本阶段目标与范围、决策与约束、已完成工作与阶段进展、产物与验证、问题/阻塞/风险、后续建议”组织。
无实质内容的分区省略；目标一句概括本条贡献，不复述全部任务描述。
通常每区 1—3 条必要要点，此数为精简目标，不能截断关键约束、风险或验证边界。
一条要点表达一个结论或行动，同一事实不跨分区重复；省略闲聊、问答过程、礼貌、自述、重复背景和操作流水。
已解决问题及不影响后续工作的失败尝试省略；未定事项放入问题，不罗列未选方案。
长日志和大段代码用证据位置替代；放弃方案仅在避免重复错误时保留一句必要原因。
计划不能写成完成，候选不能写成既定决策，建议不能解释为已授权执行。
产物名称/位置与实际验证分别表达；验证明确对象、范围及通过、未通过或未验证。

### F06-R04：一条对话一份当前记录

以固定任务和来源对话识别同一记录。再次整理更新同一当前记录，实质保存生成历史版本，不追加重复成果条目。
保留仍有效的此前成果、已确认人工纠正及删除噪音的意图；有真实新变化才提出新候选。
不反复恢复用户已删除的同一噪音，不在确认前重新压缩或改写人工编辑结果。

### F06-R05：任务概况候选

先形成本条记录候选，再基于当前概况、候选和必要的其他当前正式记录提出概况更新。
概况表达任务整体进展、有效决策与约束、成果索引、未决问题和下一步，不全文拼接所有记录。
其他对话有效成果与用户修正保留；不把本对话的局部认识当任务全部事实。
冲突标注来源，可保留“待确认结论”；阶段新进展取代旧进度不等于早期事实当时错误。
任务标题、目标、状态仍由任务字段提供；候选不能维护第二份可覆盖的看板状态。

### F06-R06：活动草稿与预览

同任务的同一对话最多一份活动记录草稿；重复点击打开同次进度或草稿，不再次派发。
不同对话允许各有活动草稿，不设任务级全局锁。一组成对更新只有一个活动确认身份。
预览提供当前正式值、AI 原稿和人工结果；分区拒绝变化表示保留原值，不能误作删除。
记录事实编辑后必须按 F07 核对概况；“待确认结论”可正式保存，“概况待核对”阻止正式保存。

### F06-R07：一次确认与正式生效

一次确认使记录及概况一致生效，写入确认时间、上一版本、来源、来源版本、整理截止与 AI/用户结果。
失败时维持此前成对正式结果，默认读取不能见到半份新事实。只有成功后更新卡片、版本、待确认数量和读取结果。
连点、超时重试、多入口或多窗口处理同一确认只生效一次；已处理入口显示实际结果。
只为有实质变化的对象生成版本；记录未变但概况变化仍需审核保存，不制造相同记录版本。
未结束工作不因整理变成成果，确认不改变任务字段、不停止其他对话、不接续开发。

### F06-R08：提示与处理位置

正式内容版本与上次成功整理处理位置分别保留。仅“有变化且保存成功”或“成功判断两部分均无需更新”推进位置。
无变化结果不制造版本或确认数量；任一对象变化仍走成对审核，不按记录未变跳过概况。
生成草稿、保存失败、取消或放弃含变化草稿均不推进位置、不清除“有新内容待整理”。
处理后整理消息不触发新内容提示；之后实际新增交流再提示。提示不阻止新建对话或完成任务。

## 5. 异常、取消与恢复

- 未关联时取消选择：保持未关联，无记录或草稿；已创建目标但关联失败：保留任务，只重试关联同一目标。
- 已明确关联后取消整理：只取消整理，不自动解除固定归属。
- AI 失败或不可用：显示原因，正式内容不变，保留输入和候选，允许重试或手动概况维护，不假称已整理。
- 来源不可读：保留既有记录与来源标识，不能虚构整理成功；可手动维护概况或另开工作对话。
- 保存失败：保留候选、人工编辑、选择与提示；重试同一确认，不重建任务或对话。
- 取消或放弃：不删除正式记录、不取消任务、不影响其他草稿；之后仍可从全部已结束工作重新提炼。
- 重启或执行结果未知：恢复原身份和已保存草稿，先核对真实结果，不猜完成或自动重发。
- 来源或概况基线变化：保留候选，按 F08 核对受影响对象，不能覆盖当前值。
- 来源任务已删除时由 F17 关闭形成记录入口并说明原因，不改绑、不保留任务待整理提示。
- 连点：按 REC-02，同一次提交的连点/重试不重复产生对象。
