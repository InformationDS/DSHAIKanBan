# F11：默认背景准备与发送时自动同步

| 属性 | 内容 |

## 1. 目标与范围

用户新建或继续工作对话时，下一次明确发送能自动使用当前适用背景。
准备背景、预览背景、打开对话和实际提供背景是四种不同事件。
本功能包含默认范围、发送时比较、净变化同步、实际使用登记与取消。
不包含批量预加载详细记录、历史比较、其他对话原文查证或后台自主工作。
F12 后续提供详细读取；本功能先提供可靠的背景使用合同。
没有概况或总览时仍允许工作，不为填满预览制造内容。

## 3. 用户流程与界面职责

1. 用户打开新建或已有对话，看到归属、背景准备情况和输入框。
2. 未关联对话预览项目背景；任务对话额外预览任务信息和概况。
3. 正式背景更新后，已有对话可提示“背景有更新，下次发送时自动同步”。
4. 用户输入要求并发送，系统核对项目、归属、正式版本与修正标识。
5. 生成本轮明确快照，将必要更新与用户要求一起提供给工作。
6. 确认实际提供后登记对应版本、内容基线与修正标识。
7. 对话简短显示本轮同步主题，可展开实际内容和版本。
8. 用户取消尚未使用的准备，保留输入与上次实际使用基线。

预览说明内容将用于所选 AI，临时补充属于本轮要求。
展开面板展示实际范围，不把可访问材料数量等同于已读材料。
默认范围不因用户浏览历史页面而扩大。

## 4. 功能规则

### F11-R01：默认范围

未关联对话只准备当前项目与工作范围、当前正式总览、本轮要求。
归属任务存在时额外准备标题、目标、状态、适用阻塞原因、当前正式概况及必要来源/待更新提示。
来源任务已删除时只准备项目背景，保留原任务来源标识。
草稿、其他对话完整消息、全部索引、全部历史和工作目录文件均不默认进入背景。
新对话准备尚未完成可等待或明确暂不带背景，不能静默漏带；已有对话同步失败不能沿用旧背景。

### F11-R02：发送触发

只有用户发送本轮要求才派发工作；打开、保存背景、关联、预览均不执行。
背景更新不唤醒闲置 Agent，也不隐式排队执行忙碌对话。
发送前正式背景变化时刷新可见预览，并在该轮确定快照。

### F11-R03：版本与修正合同

分别记录任务信息、概况、总览的最近实际内容基线与版本，另记录有效修正标识。
比较任务标题、目标、状态和阻塞原因；不能只看正文版本号。
正文版本不变但关键结论被否定或替代时，仍识别变化并带上必要修正。
修正范围须限制在关联任务/项目，不按同名词使其他任务结论失效。

### F11-R04：净变化与降级基线

跨多个版本直接比较实际使用基线与当前内容，不加载每个中间历史。
未变对象不重复追加全文；必要变化包含约束、风险、删除/替代结论和未决问题。
基线不可靠时提供当前精简正式背景及必要修正，不读全历史兜底。
精简不能静默丢长期约束或风险；过长时提示精简或明确范围。

### F11-R05：初次绑定

首次绑定后下一次发送提供当前任务信息与概况，项目总览按已有使用基线判断变化。
运行中绑定不改当前输入，不声称任务背景影响了关联前工作。
不复制绑定前原始聊天，也不自动将其结论写入概况。

### F11-R06：实际使用登记

内容确实提供给本轮工作后才登记版本、快照和修正标识。
准备、预览、复制、关联、失败或结果未知都不登记使用成功。
同一请求重试须复用请求身份并核对实际结果，不重复派发或追加背景。
快照发送后的正式变化用于下次发送，不能替换正在执行输入。

### F11-R07：取消与透明性

取消尚未使用准备不改变正式材料和上次使用基线，之后发送重新检查当前背景。
已经读入的旧内容无法撤回，后续以必要修正为准，不宣称清空上下文或零消耗。
实际提供内容、对象版本、修正与本轮补充可展开检查；未决问题不冒充确定依据。
本轮补充不自动持久化为长期约束，保存正式材料需走对应编辑确认流程。

## 5. 异常、取消与恢复

| 场景 | 用户结果与恢复 |
| --- | --- |
| 准备/自动同步失败 | 输入保留，提示失败及重试；不静默使用旧背景发送 |
| 送达或执行结果未知 | 标为需核对，不登记成功、不自动重发；核对后只重试缺失步骤 |
| 重复点击发送 | 同轮一个有效请求；展示同一结果，不重复追加背景 |
| 来源任务删除 | 取消未使用任务背景，下一次仅项目背景；不伪称历史聊天已清除 |
| AI 不可用 | 本地预览仍可看，发送说明原因；输入保留，允许复制背景 |
| 正式内容变更 | 发送前刷新，发送后留待下一次；不自动执行 |
| 重启 | 恢复归属与可核实使用基线，未知状态核对；不开启工作 |
