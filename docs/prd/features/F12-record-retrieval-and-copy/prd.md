## 1. 目标与范围

用户继续工作需要细节时，AI 能查到直接相关的当前正式材料及适用修正。
用户也能复制与新对话默认范围一致的当前任务背景，交给外部工具使用。
本功能包含同项目检索、分层读取、去重、透明性、明确历史追溯和复制反馈。
不包含跨项目检索、全量原文兜底、外部 AI 跟踪或项目备份导出。
当前事实、历史材料、用户补充与草稿必须保持不同来源和用途。
普通正式材料读取不增加逐次确认；原始聊天和历史读取遵守明确意图边界。

## 3. 用户流程与界面职责

1. 默认背景不足以回答当前问题时，AI 查询简短相关索引。
2. 先查当前任务记录，再查相关项目成果，仍不足再查同项目直接相关任务记录。
3. 根据索引选当前版本的必要片段，随片段带来源、适用状态及验证范围。
4. 片段不足时扩大到必要分区或单份记录，材料已足够则停止。
5. 对话简短显示实际读取对象与主题，可展开实际内容、版本和用途。
6. 正式记录仍不足以查证时，说明缺失和拟查看聊天来源，由用户决定范围。
7. 用户明确追溯/比较时，仅读取指定历史对象与版本，标识为追溯用途。
8. 任务详情“复制当前任务背景”打开预览，允许本次补充后复制。

没有命中时说明当前正式材料不足，不以全量历史掩盖空结果。
复制预览必须显示实际文本，与新对话默认范围一致。
查看列表和全文本身不向 AI 发送内容。

## 4. 功能规则

### F12-R01：同项目最小检索

查询范围绑定当前项目，必要时过滤当前任务及直接相关来源。
默认不预加载全部索引；按问题查询标题、简介与来源标识后再选对象。
同项目其他任务的相关正式记录可自主读取，不改变对话任务归属。
首版禁止跨项目检索，不后台扫描磁盘或其他项目补事实。

### F12-R02：片段优先与扩展

默认返回相关结论片段、必要上下文、来源与验证范围，不返回全量正文。
片段不足才逐步扩大到分区或一份完整记录，足以推进时停止。
读取一份记录不连带返回其他记录、历史版本、原始聊天或全部工作文件。
实际代码/设计稿由宿主文件能力处理，记录可检索不代表文件已预加载。

### F12-R03：适用性必须随读取

当前工作模式返回当前适用事实及必要修正，否定/替代原句不混入事实正文。
追溯模式保留原文同时展示当前修正、影响范围和来源关系。
待确认结论返回为未决问题；验证 A 不证明替代方案 B 已验证。
同名但不同任务的结论不随本任务修正失效；未确认草稿不作为正式依据。

### F12-R04：去重与变化

以对话实际读取记录的内容、版本和修正标识判断是否重复。
同一未变片段不重复追加；更新后按问题提供必要变化及修正。
过去已读内容无法撤回，不能承诺自动清除旧上下文或零消耗。
后台正式更新不唤醒对话；再次读取或发送时识别相关修正。

### F12-R05：历史与聊天边界

历史仅按用户明确的追溯、比较或恢复意图读取指定对象/版本/范围。
对象不明确时只澄清必要范围，不扩大到所有历史；追溯不改当前事实。
其他对话原文须先说明正式材料缺失及拟读取来源，由用户决定是否和范围。
不把历史页面已展开、旧版本数量或可访问权限当作默认读取授权。

### F12-R06：复制与可读交接

复制文本只含当前项目、总览、任务信息、概况、必要提示及本次补充。
不默认附带所有记录、聊天或历史；明确复制历史须标对象/版本与用途。
可读交接文档采用同样当前背景范围，不含可恢复项目数据或历史全文。
复制不创建对话、不登记使用、不改正式记录、不追踪外部 AI 状态。

### F12-R07：内容与反馈透明

实际读取对象、版本、主题、用途及有效修正可展开核对。
本轮补充不成为长期约束；敏感信息可在确认/复制前删除。
复制成功后才提示成功；剪贴板失败提供可选择文本供手动复制。
外部成果仅在用户主动输入并确认或手动修正后成为正式材料。

## 5. 异常、取消与恢复

| 场景 | 用户结果与恢复 |
| --- | --- |
| 检索/读取失败 | 报告失败对象与原因，可重试；不编造命中或读取成功 |
| 来源变化/删除 | 重新核对当前对象和修正，缺失明确；不改用同名任务 |
| 用户取消原文读取 | 不读取额外原文，保留当前问题和已有正式材料 |
| 连点复制/读取 | 不重复登记或追加同一内容；复制反馈对应实际结果 |
| 剪贴板失败 | 展示可选择文本，可重试或手动复制，不显示成功 |
| AI 不可用 | 查看与复制本地内容可用，AI 自主检索说明不可用 |
| 重启 | 保留可核实使用信息，未完成额外读取不自动重放 |
| 内容过长 | 提示精简/明确范围，必要风险与约束不静默裁剪 |

## 7. 实施边界与交接

允许调整索引和展开呈现，不得以权限可读为由自动扩大实际上下文。
不提供备份导出或外部自动同步；可读交接输出与项目数据备份必须区分。
交付检索与复制范围合同，供 F13/F20 共用，记录实际使用去重依据。
实现前创建 implementation.md；验收时创建 verification.md；进度不在本 PRD 内维护。
