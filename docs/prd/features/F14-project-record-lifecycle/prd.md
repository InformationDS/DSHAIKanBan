# F14：任务重开与项目成果更新

| 属性 | 内容 |
| --- | --- |
| 功能编号 | F14 |
| 优先级 / 阶段 | P0 / S4 |
| 原始来源 | FR-24、FR-25；§7.6、§6.5、§5.6 |
| 前置依赖 | F13；继承其任务状态、来源修正、成对核对和保存能力 |
| 验收来源 | AT-41—42、45、56、66、70；AT-07—08 与 F17 联合 |

## 1. 目标与范围

已形成项目成果的任务继续推进时，旧成果作为前次完成事实保留，新来源变化明确提示。
任务再次完成后更新同一成果条目，保持历史可追溯，避免把同一任务重复累计。
本功能包含任务重开、来源变更检测、草稿完成范围核对和来源缺失后的手动纠正。
不包含后台重生成、自动重开/完成任务、自动删除成果或从同名任务恢复来源。
已保存成果、当前看板状态、当前源材料和当前草稿是不同对象与状态。
任务归档与永久删除的具体执行由 F17 负责，本功能提供成果的联动合同。

## 3. 用户流程与界面职责

1. 用户把已完成任务改为进行中等非完成状态。
2. 当前成果保留并注明代表前次完成，界面显示任务当前状态。
3. 正式任务概况或所用任务记录发生变化后，成果显示“项目记录待更新”。
4. 用户继续形成并确认任务记录，未自动改动旧成果或项目总览。
5. 再次明确完成任务，进入“更新项目记录”，按现有材料和缺失范围生成。
6. 同屏展示该成果条目与总览的新旧差异，一次确认更新。
7. 历史保存前次版本，成果列表仍只有该任务一个当前条目。
8. 来源删除/不可用后，展示缺失来源和截止，允许手动纠正已保存事实。

生成过程中重开任务，保留草稿并展示完成范围变化，需要核对后再处理。
成果列表仍可返回存在的任务；来源任务已删除时返回项目，不指向同名新任务。
需要更新与可以确认须使用不同提示。

## 4. 功能规则

### F14-R01：成果稳定标识

每个任务最多一份最新正式项目记录，多轮更新保留同一成果身份。
新版本可以改变正文、来源与截止，不能生成第二个当前成果累计同任务。
保存历史供追溯，但历史版本不进入当前成果数量或默认背景全文。

### F14-R02：任务重开

用户改状态才重开任务，成果保存或修正不能自动改变状态。
重开不删除当前项目记录，也不抹除总览中已确认事实。
成果明确代表前次完成，不声称当前任务已再次完成。
任务状态来自字段，总览与成果的截止文字不覆盖卡片状态。

### F14-R03：来源变化与待更新

比较成果采用的概况、正式任务记录版本及有效修正标识与当前来源。
被采用来源发生实质变化后显示待更新和具体变化来源，不后台重生成。
无关任务变化不凭同名结论触发本成果失效；来源修正按范围执行。
短提示进入总览/默认背景，完整历史和全部来源正文不因此自动加入。

### F14-R04：再次完成与更新

再次完成不自动生成；用户点击更新才发起新的系统整理。
更新继续使用 F13 的缺失检查、受控来源、成对预览与一次保存。
新的正式版本保留前次版本，当前列表同一条目替换当前版本引用。
来源不齐按已知截止表达，不把新增目标推断成已经完成的成果。

### F14-R05：草稿中重开或来源更新

生成/审核期间任务重开，草稿与人工编辑保留，标记完成范围变化需要核对。
正常确认当前完成成果仍要求任务已完成，不能无提示保存为已再次完成。
来源概况/记录或总览更新后，核对受影响部分与最新基线，不废弃整个成果草稿。
核对后仍有实质变化须让用户看新差异再确认，不自动保存重新计算结果。

### F14-R06：来源删除或不可用

保留已保存成果、来源标识和原任务名称，标注来源已删除/不可用。
允许手动纠正已保存事实，来源类型为用户，并核对总览影响。
禁止自动使用其他同名任务作为来源重新生成，也不重新创建已删除任务。
删除源数据后缺失内容不伪装可查，历史对话不宣称被成果操作清除。

### F14-R07：修正优先与范围

读取引用失效结论时随引用显示已确认修正，不等重生成才阻止失效句作为当前事实。
AI 后续更新遵守已有人工修正、验证范围和未决问题，不因整理改写重新恢复效力。
手动纠正旧成果说明覆盖依据/截止但不强制填写理由，不回写原始聊天。
成果历史恢复仍按 F10 新版本预览与核对，不撤销后续修正或回滚任务状态。

## 5. 异常、取消与恢复

| 场景 | 用户结果与恢复 |
| --- | --- |
| 重开保存失败 | 原任务状态与正式成果一致保留，输入保留，可重试 |
| 更新失败/取消 | 旧成果仍可读，草稿/编辑按规则保留或明确放弃 |
| 连点/并发更新 | 同次结果复用，同成果旧草稿核对最新版本，不重复条目 |
| 生成中来源缺失 | 保留草稿，说明缺失与影响，不按同名对象代替 |
| AI 不可用 | 待更新提示仍可见，本地手动纠正及总览核对可用 |
| 重启 | 恢复当前成果、截止、修正及待更新依据；不自动生成/派发 |
| 总览竞争修改 | 独立成果编辑保留，仅核对最新总览与相关冲突 |

## 7. 实施边界与交接

允许调整截止与待更新的呈现；不能把来源变化解释为旧成果必须删除。
不新增“重新生成即自动确认”，不将任务重开作为抹除历史的操作。
输出来源变更与成果范围提示合同，供 F11/F12/F15/F17 接入。
实现前创建 implementation.md；验收时创建 verification.md；进度不在本 PRD 内维护。
