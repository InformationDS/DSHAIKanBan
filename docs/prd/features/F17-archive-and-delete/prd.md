## 1. 目标与范围

用户可把任务从活动看板归档并恢复，或在明确影响后永久删除归档管理数据。
归档不改任务状态、不停止 AI；永久删除不删除原始聊天、代码或既有项目成果。
包含归档/恢复、普通撤销、归档查看、删除影响预览和删除后的固定来源降级。
不提供删除后恢复、备份还原、聊天清理或任务关系转移。
项目备份 FR-27 暂不在首版，不能用它替代不可撤销提示或作为删除前置条件。

## 3. 用户流程与界面职责

1. 任务更多操作归档，显示任务从活动看板隐藏；运行工作继续的提示准确。
2. 在归档列表查看任务、记录及历史，或通过含归档搜索打开。
3. 点击恢复，回原状态；可用则回原排序位置，否则放列末尾。
4. 普通归档/恢复提供撤销，竞争变化时先核对。
5. 已归档任务更多操作提供永久删除，展示完整影响和不可撤销说明。
6. 有运行工作时提示先结束当前工作，删除操作本身不代为停止。
7. 用户二次确认并成功删除后，任务消失，原对话及项目成果保留删除来源标识。

删除确认同时说明对话以后不能形成该任务记录、不能改绑，无需第三层弹窗。
删除来源对话用“返回项目”替代返回任务，不能跳不存在的详情。
已归档、已删除与加载失败必须区分，不能把失败标成删除成功。

## 4. 功能规则

### F17-R01：归档仅改变可见性

归档保留任务状态、字段、四类正式内容、来源、版本、草稿和对话关系。
不停止 AI，不删除成果，不自动移除总览中的已确认贡献。
运行中归档提示工作仍继续，不宣称当前任务暂停了所有执行。
恢复回原状态，原位置无法恢复放相应列末尾，不猜测其他项目位置。

### F17-R02：归档期间操作边界

允许查看归档内容和搜索，不允许未恢复就新建工作、发起整理或正常确认记录；任务记录及项目成果记录都须先恢复来源任务再正常确认。
已有整理可完成为草稿，不能自动正式确认；草稿保留供恢复后审核。
普通归档及取消归档可撤销，已有后续修改时不得用旧撤销覆盖新事实。
归档状态不解绑对话、不使其可用于其他任务。

### F17-R03：永久删除条件

仅已归档任务提供永久删除入口。
删除前核对真实运行工作，仍运行则先结束当前工作，再重新核对删除条件。
删除本身不是停止动作，不能后台停止后宣称用户已授权。
未停止、停止失败或结果未知时不能按已停止继续删除。
确认过程中任务已恢复或有新工作等实质变化时，重新核对并展示当前影响。

### F17-R04：删除影响预览

明确列出任务字段、概况、对话任务记录、版本、草稿和管理关系的删除影响。
同时说明原始对话与代码保留、已有项目成果及必要来源标识保留。
关系不再提供任务管理访问，但固定来源不能释放或改绑。
文案包含“永久删除不可撤销”及“对话保留，但无法继续形成该任务记录，也不能改绑”。
用户二次确认后才删除；取消确认保留所有当前数据。

### F17-R05：成果保留与来源

已经进入项目的成果保留已确认内容、完成截止与必要来源标识，注明源任务已删除。
不把删除卡片当撤销项目成果，不自动从总览移除贡献。
已删除任务记录不再是可打开的来源，成果不能链接到不存在的任务正文。
同名新任务有新标识，成果和对话来源不会改指向它。
关联适用性修正及已确认来源说明仍随保留成果可见，不回退为无标识旧事实。

### F17-R06：删除来源对话能力

保留原任务名称/标识和原始对话，显示“来源任务已删除”。
可查看并继续聊天，不读取已删除概况或任务记录，只可按项目范围准备新背景。
“形成任务记录”禁用并说明“来源任务已删除，无法形成任务记录”。
返回任务替换为返回项目；不生成该任务新记录、草稿或待确认提示。
不显示有新内容待整理，不把继续聊天后的新消息转成不存在任务的整理请求。

### F17-R07：背景与筛选持久边界

删除时取消尚未用于工作的任务背景准备；实际已读内容不能声称撤回或清除。
后续发送按 F11 用项目背景，不伪造新任务或映射同名任务。
删除来源对话仍在项目“全部”和“已关联”中，不进入未关联，不新增专门筛选。
重启后保持删除来源、记录限制和不可改绑关系。

### F17-R08：保存结果

归档/恢复/删除失败保持此前正式结果，显示实际失败和可重试步骤。
连点与未知结果重试先核对实际对象状态，不重复操作、不误删新对象。
成功后再同步列表、提示、草稿数量和背景入口，不显示部分删除的整体成功。
不把旧草稿恢复为已删除任务的正式内容或重建任务。

## 5. 异常、取消与恢复

| 场景 | 用户可见结果与恢复 |
| --- | --- |
| 归档/恢复失败 | 保持原可见性和状态，输入/选择保留，可重试 |
| 删除确认取消 | 不删除、不停止工作，保持归档任务 |
| 运行未结束/未知 | 提示核对工作，删除不继续，不自动停止 |
| 删除失败/未知 | 先核对实际保存范围，不报假成功、不盲目重放 |
| 竞争恢复或新增工作 | 刷新影响与条件，由用户再核对，不按旧确认直接删 |
| 草稿已生成 | 归档保留并要求恢复后确认；删除预览列出其影响 |
| 连点 | 按 REC-02，同一次提交的连点/重试不重复产生对象。 |
| AI 不可用 | 归档、查看和管理仍本地可用；运行状态需可靠核对 |
| 重启 | 恢复归档或删除来源事实，不复活任务、不解绑、不自动重发工作 |
