# F18：中断恢复、保存反馈与 AI 降级

| 属性 | 内容 |
| --- | --- |
| 功能编号 | F18 |
| 优先级 / 阶段 | P0 / S5 |
| 原始来源 | FR-28、FR-29、FR-31；§7.8、§13、§15.2—15.3 |
| 前置依赖 | F08、F10、F11、F13、F17；宿主持久化和执行结果查询能力 |
| 验收来源 | AT-10、24、47—49、54、63、70、84、90、93、104、122 |

## 1. 目标与范围

用户连续使用、关闭重启或遭遇失败后，能够判断哪些内容已保存、哪些工作需要核对。
AI 不可用时仍可维护本地任务、正式内容与历史，不强迫调用 AI 保存用户修正。
本功能补齐跨流程恢复和降级体验，并验证前置功能已具备的可靠保存合同。
不是在 S5 才开始实现原子保存、草稿保留或幂等；这些规则从对应功能首次实现即有效。
不包含项目备份、导入、覆盖恢复、自动备份，也不自动重放未知工作。
验收覆盖任务、对话归属、背景、成对候选、历史与删除来源的联动。

## 3. 用户流程与界面职责

1. 编辑时明确显示未保存、草稿已保存或正式确认成功。
2. 用户发起确认，界面显示保存中，成功后才更新正式读取和计数。
3. 失败时保留输入、候选与选择，说明具体失败步骤并提供重试。
4. 重启恢复原项目、任务、对话与已保存草稿，不创建替代对象。
5. 无法核实的运行、背景准备或确认结果显示需核对。
6. 用户查看已知结果后，重试尚未成功步骤，不自动重发要求。
7. AI 不可用时显示原因和本地替代入口，用户手动修正记录及对应汇总。
8. 恢复 AI 后仍在原任务/归属，不把离线维护重做为另一套对象。

数据读取失败应显示错误与重试，不把损坏数据当空项目覆盖。
本地保存不代表 AI 调用离线，发送区域说明所选 AI 的使用范围。
查看损坏项目前保留已有存储和可恢复线索，不猜测另一个目标项目写入。

## 4. 功能规则

### F18-R01：保存反馈

草稿持久化、未保存编辑、正式确认成功分别表达，不统一显示“已保存”。
草稿保存不改变正式上下文、版本、卡片进展或项目总览。
保存中、失败和结果未知不显示正式成功；成功结果必须可核实。

### F18-R02：成对一致与幂等

任务记录/概况和项目记录/总览作为同一用户操作一致生效。
任一步失败都不能让其中一半成为正式读取结果。
连点、超时重试和多窗口同一更新只产生一个有效结果。
成功后仅实质变化对象有新版本；重试不重建任务、对话、成果或更新身份。

### F18-R03：中断核对

恢复正式内容与已保存草稿，未保存输入不伪装已恢复成功。
未知运行、准备或确认结果需核对，不猜完成、不自动重发工作。
已有成功步骤不重复执行；创建成功归属失败只补归属/准备步骤。
关闭重启不自动启动闲置对话，不因恢复读入全历史。

### F18-R04：竞争与损坏

同记录旧稿保留编辑并核对当前版本，不直接覆盖。
不同记录竞争汇总只核对最新汇总，独立记录事实不整体废弃。
数据损坏/读取失败不清数据、不覆写为空项目；范围不明不写猜测项目。
错误状态与真实空状态分开，恢复失败原因和下一步可见。

### F18-R05：本地降级能力

任务创建/编辑、状态、归档、搜索、四类内容查看/手动编辑、历史和复制仍可用。
修改记录时可同次手动修正汇总或确认无需修改，不要求必须请求 AI 建议。
有一致性待核对仍不能跳过核对，但手动核对可完成后一次保存。
AI 草稿生成、辅助汇总及发送工作提示不可用原因，不伪称已完成工作。

### F18-R06：故障分类

AI 不可用、对话不能打开、工作范围缺失、保存失败和未知送达分别表达。
空对话若可创建可保留入口，但创建成功不表示 AI 可工作。
提供针对性重试、手动维护、复制背景或桌面模型/账号设置入口。
外部成果由用户主动输入并确认，不自动追踪外部执行状态。

### F18-R07：范围与来源恢复

重启保留固定归属、人工修正、适用范围、版本与已删除来源标识。
关联、预览、复制和打开历史不登记为实际使用；未知送达不推进使用基线。
任务删除后不读已删除任务材料、不重生任务、不转移原对话归属。
默认体验统计不收聊天、记录或代码全文，服从桌面用户选择。

## 5. 异常、取消与恢复

| 场景 | 用户结果与恢复 |
| --- | --- |
| 保存写入失败 | 一致正式结果不变，草稿/选择保留，可重试 |
| 保存成功但反馈丢失 | 核对同一操作结果，显示成功一次，不制造第二版本 |
| 草稿恢复失败 | 明确失败，不假称恢复，不清已存正式内容 |
| 读取损坏数据 | 错误界面和重试，不覆写空项目，不写猜测目标 |
| 取消或关闭 | 区分已保存草稿与未保存编辑，不静默丢编辑 |
| 连点 | 按 REC-02，同一次提交的连点/重试不重复产生对象。 |
| AI 不可用 | 本地能力可用，AI 动作原因明确，有手动/复制替代 |
| 同时竞争修改 | 当前值可见，保留编辑与选择，核对后再确认 |
| 来源变化/缺失 | 保留来源标识，说明影响，不用同名对象替代 |
