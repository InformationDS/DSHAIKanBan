## 1. 目标与范围

用户在中英文、窄窗口、放大文本和键盘操作下，仍能完成任务到项目成果的核心闭环。
本功能统一语言和桌面适配体验，并对已经实现的组件执行跨流程验收。
主题继承、可读状态、键盘等效操作和编辑保护须随各组件首次实现，不延迟到 S5。
本阶段集中补齐跨页面焦点、返回、语言覆盖和窄窗口中的缺口。
不包含用户内容翻译、改变业务状态、新建示例任务或独立多页强制教程。
不抢占宿主已有全局快捷键，不重新实现桌面统一主题/字体设置。

- [对象与状态](../../common/objects-and-states.md)：OBJ-02、OBJ-06、OBJ-07。

## 3. 用户流程与界面职责

1. 首次进入看板提供短说明：建任务、开展对话、形成记录、完成后生成成果。
2. 默认界面跟随桌面主题、字体缩放和语言。
3. 用户选择“跟随应用 / 中文 / English”，标签立即切换。
4. 用户缩窄窗口，详情可改全页，主要操作、核对与保存仍可找到。
5. 用户只用键盘创建任务、打开对话、形成/编辑/确认记录和改状态。
6. 聚焦和返回路径保持可预测，回看板仍保留筛选和卡片定位。
7. Esc 取消界面动作时保护编辑，明确保存/保留/放弃路径，不静默丢失。
8. 用户查看版本时间，能够核对具体确认时间与来源。

短说明可跳过，不插入正式示例数据，不修改用户项目或任务。
状态、冲突、错误和待核对原因均有文本，不仅依赖颜色、图标或悬浮提示。
英文标签长度不同，布局应允许换行/伸缩，不能挡住确认和取消。

## 4. 功能规则

### F19-R01：宿主偏好继承

默认采用桌面主题、字体缩放和语言，跟随模式响应宿主偏好变化。
看板语言提供跟随应用/中文/English，并在选择后立即生效。
偏好作用范围遵守项目/桌面已确定合同，不修改用户业务数据或归属。

### F19-R02：只翻译界面

标签、状态显示名、按钮、错误和系统说明可以翻译。
任务标题、目标、记录正文、原始聊天、人工修正和用户输入不得自动翻译。
语言切换不改正式版本、不改变状态语义、来源标识或适用范围。
无法覆盖的宿主语言能力明确记录，不能混淆标签语言与成果生成语言。

### F19-R03：窗口与放大

宽窗口可侧栏详情，窄窗口可全页详情，两者相同业务状态与草稿身份。
返回保留原筛选、排序和定位，不跳到看板顶端丢上下文。
放大文本后允许滚动/重排，主要入口、核对原因、保存与取消不被遮挡。
长任务名、阻塞原因和英文标签不能靠裁剪唯一信息影响操作判断。

### F19-R04：键盘等效

可键盘创建任务、打开对话、形成记录、编辑两侧、核对、确认、改状态和取消。
拖拽状态有等效菜单；阻塞原因的必填与取消回原状态规则一致。
操作目标和提交反馈有可读文本，按钮禁用原因可获取。
不自设冲突的全局快捷键，局部快捷键只在对应界面上下文生效。

### F19-R05：焦点与编辑保护

打开详情/预览焦点进入可操作内容，关闭后回到触发入口或合理邻近项。
模态审核期间焦点不跳进背景页面，操作完成后有明确反馈。
Esc 不静默丢编辑；有修改时提供清楚的保留/放弃路径或保留草稿。
焦点不因后台提醒、更新或语言切换擅自跳离输入位置。

### F19-R06：状态文本与来源

未开始、进行中、已阻塞、已完成、已取消均有文本表达。
整理中、草稿已保存、待确认、汇总待核对、失败和已处理彼此可辨。
内容中“待确认结论”和“汇总一致性待核对”不得用相同含糊标签代替。
被否定/替代片段、来源已删除和待更新原因不只依赖颜色。

### F19-R07：入门与时间

首次真实使用采用短说明，不强制多页教程，不写入正式示例任务/记录。
时间显示按用户偏好，版本详情保留可核对的时间信息。
相对时间可用于列表，但版本详情不能只用“刚刚”掩盖实际确认时间。
中文/英文与时间显示切换不生成业务版本或重置列表数据。

## 5. 异常、取消与恢复

| 场景 | 用户结果与恢复 |
| --- | --- |
| 语言/主题切换时正在编辑 | 输入、选区和草稿保留，不自动提交或重启生成 |
| 窗口变化 | 同一任务/候选状态保留，可继续操作与返回 |
| Esc/关闭编辑 | 明确保留或放弃，不静默丢编辑，正式内容不提前变化 |
| 翻译标签较长 | 自适应显示，关键操作和状态仍可获取 |
| 保存失败 | 可用键盘访问错误与重试，焦点仍在合理位置 |
| 连点 | 按 REC-02，同一次提交连点/重试只产生一个对象，不重复。 |
| AI 不可用 | 本地操作与错误文本可访问，依赖 AI 的入口说明原因 |
| 来源/正式内容变化 | 文本表达核对原因，不凭颜色自动替换编辑 |
| 重启 | 恢复已有偏好/草稿按宿主合同，不造示例数据或自动运行 |
