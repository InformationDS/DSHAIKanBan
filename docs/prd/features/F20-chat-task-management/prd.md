## 1. 目标与范围

用户能在聊天中查询和明确管理当前项目单个任务，结果与看板使用同一事实与保存机制。
单任务明确管理为 P0，不因它位于 S5 而降为候选功能。
本功能包含查询、创建任务、改字段/状态、新建/关联对话、形成任务记录和生成项目记录入口。
普通可撤销管理不反复要求确认；AI 成果草稿仍必须具体预览后由用户确认。
不包含批量清单创建（P1）、模糊目标自动拆整个项目（P2）、跨任务转移或自动判定完成。
“本条对话工作结束”“任务完成”“生成项目记录”必须分别识别。

## 3. 用户流程与界面职责

1. 用户查询当前任务/看板/概况/总览，返回当前正式内容或具体记录入口。
2. 明确创建或修改任务时，识别当前项目与必要目标，调用同一业务动作。
3. 模糊或多个同名目标时只澄清必要对象，不擅自管理整项目。
4. 动作完成后报告实际保存结果，给任务/记录入口便于核对。
5. 明确任务内新建或关联当前对话，遵守同项目唯一归属提示。
6. 未关联对话要求形成任务记录时，引导选择/创建任务后再整理。
7. 明确生成项目记录须对应已完成任务，自动发起系统整理并进入成对候选预览。
8. 用户在具体预览确认，成功后聊天和看板反映同一正式结果。

用户只说“这条对话的工作完成了”，不能自动把卡片移到已完成。
用户明确完成任务时只执行任务状态动作，不顺带生成项目记录。
普通查询不批量返回全历史，历史请求需明确对象、版本和用途。

## 4. 功能规则

### F20-R01：查询与项目范围

查询绑定当前项目，当前任务信息、看板、正式概况/总览与记录入口可返回。
无任务归属时明确“未关联任务”，不从聊天内容猜任务、不后台绑定。
来源已删除时保留原任务名称/删除标识，不读已删除内容，不变成未关联候选。
普通查询不返所有历史正文，也不后台扫描其他项目/全磁盘。

### F20-R02：明确管理与实际保存

明确创建、改字段/状态可直接执行普通可撤销动作，报告真实保存结果。
目标不明确时只确定必要项目/任务/字段，不自动拆解成多任务。
状态与阻塞原因遵守 F02，重复请求/未知结果先核对，不能重复创建。
失败保留要求和必要参数，不声称已保存或将候选字段当正式字段。

### F20-R03：三个意图分开

对话阶段结束不等于任务完成，记录生成/确认也不自动改任务状态。
用户明确完成任务才变更状态；完成不自动触发成果生成。
用户明确生成项目记录才进入 F13，检查完成与缺失来源后生成候选。
模糊“完成了”必须结合具体指向确定必要目标，不能顺带完成和生成所有对象。

### F20-R04：对话创建与关联

可明确在项目内新建未关联对话，任务选择不是必填。
可明确在任务下新建对话，或关联当前同项目未关联对话。
展示固定归属和不可解除/改绑后果，普通入口用就地提示，不增加无必要弹窗。
已绑定对话不能转移、解除或在任务删除后改绑，需新对话推进另任务。
运行中关联不打断本轮，任务背景用于下次明确发送，不伪造以前已使用。

### F20-R05：记录与成果候选

形成任务记录对应具体任务与本条工作对话，在原对话发整理要求。
未关联先选择/创建任务；取消不造记录，已明确绑定后取消整理不解除归属。
项目成果对应已完成任务，用新的系统整理对话，不继承工作聊天全文。
整理只读必要材料和生成草稿，不改代码、不执行验证、不自动确认正式内容。

### F20-R06：具体确认边界

普通可撤销字段修改不反复确认；永久删除等影响动作走对应明确影响确认。
AI 记录和汇总仍具体预览一次确认，聊天“生成”不能绕过核对直接正式保存。
存在一致性待核对时不能确认成功；手动核对可用，不强制调用 AI 建议。
权限审批、回答问题、任务管理和记录确认使用不同名称，不提供跨性质全部确认。

### F20-R07：读取与使用登记

当前背景实际提供给工作时登记版本、内容基线及修正标识，遵 F11。
仅看卡片、打开入口、关联、复制或浏览历史不登记材料已用于工作。
明确追溯只读指定对象/版本并标用途，不改变当前正式事实。
额外正式读取遵 F12，其他对话原文由用户决定范围，不能全量历史兜底。

## 5. 异常、取消与恢复

| 场景 | 用户结果与恢复 |
| --- | --- |
| 目标不明/同名多个 | 只澄清必要目标，不产生管理变化、不猜测项目 |
| 保存失败/结果未知 | 明确失败/需核对，保留参数，先查同次结果再试 |
| 重复指令/连点入口 | 复用同次动作/候选，不重复任务、对话或版本 |
| 关联或选择中取消 | 无虚构记录；已创建/绑定结果核对，成功步骤不重复 |
| 来源删除/已绑定别任务 | 保留标识，拒绝改绑，提供返回项目/新建对话路径 |
| AI 不可用 | 本地看板管理和手动维护仍可用，聊天 AI/整理说明原因 |
| 正式来源/状态变化 | 当前值核对，不用聊天旧值覆盖新字段/总览 |
| 重启 | 固定归属与保存结果保留，不自动重放聊天管理动作 |
