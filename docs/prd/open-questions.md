- 来源：基线 FR-14—15、17.5 第 2 项。
- 状态：业务尚未完整定义，需要在 F06 的运行中整理入口实现前明确。
- 已确定：正常路径是相关对话工作结束后点击整理；默认整理期间无新增工作。这是使用假设，不是全项目工作必须同时结束的强制关卡。
- 待定：工作正在运行时点击如何给出最小可理解反馈。停止、失败、等待回答/审批及重启后队列行为暂不定义。
- 实施限制：不要自行实现等待队列、自动触发整理、调度或强制全项目串行；也不要擅自把禁用按钮/自动停止当已确定产品方案。正常已结束工作路径可先实现，运行中分支单独保留待定标识，不能宣称完整入口已验收。
- 需得到的决定：明确入口可见/可用行为、提示文字和是否留下待处理意图；涉及范围若扩大，另行更新需求及验收。
- 完整首版判断：处理这一局部边界后方能完成对应入口验收；不凭空增加原 106 场景中的队列验收。
